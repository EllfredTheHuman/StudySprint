# 🚀 StudySprint

**StudySprint is a game-based learning platform that makes studying fun.**

Instead of just answering questions, students can compete, work together, and play exciting educational games while learning school subjects.

## ✨ Features

* 📚 Study by subject and topic
* ⚡ Sprint Mode for quick practice
* 🎮 Multiplayer educational games
* 🏰 Castle Defence classroom mode
* 👥 Join games with a code
* 📈 Track your progress and improve over time

## 🎯 Our Goal

We believe learning should be something students **want** to do.

StudySprint combines studying with teamwork, strategy, and competition to create an experience that's engaging both in the classroom and at home.

## 🛠️ Current Status

StudySprint is currently in active development.

Features, artwork, gameplay, and the website are all subject to change as the project grows.
